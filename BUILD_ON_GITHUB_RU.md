# Как получить JAR через GitHub Actions с телефона

1. Создай пустой GitHub-репозиторий для этого мода.
2. Загрузи в него **всё содержимое** папки `BlockShapeVisualizer` (не саму папку-обёртку).
3. Открой вкладку **Actions** и разреши запуск GitHub Actions, если GitHub попросит. Workflow запускается только вручную, чтобы случайные загрузки файлов не запускали сборку и не расходовали минуты.
4. Запусти workflow **Build BlockShape** через **Run workflow**.
5. После завершения открой успешный запуск и скачай artifact `blockshape-visualizer-26.3-fabric`.
6. Распакуй artifact и возьми JAR без суффикса `-sources`.

Если workflow завершится ошибкой, пришли полный лог сборки. Не устанавливай JAR, если сборка красная или упала.
