# Block Shape Visualizer — Minecraft 26.3 / Fabric

Клиентский мод, показывающий реальные Collision Shape блоков вокруг игрока.
Серверная установка не требуется.

## Функции
- Отображает физическую форму столкновения, а не полный куб блока.
- У каждого типа блока свой стабильный цвет.
- Настраиваемый горизонтальный радиус 2–16 блоков (по умолчанию 6).
- Независимая высота поиска: вниз и вверх от игрока по 0–16 блоков (оба значения по умолчанию 3).
- Настраиваемая толщина контура 1–6.
- Можно выбрать один общий цвет или автоматические цвета по типам блоков.
- Частота перестройки моделей зависит от выбранного профиля качества, чтобы уменьшать нагрузку на слабых устройствах.
- `low`: радиус 4 блока, высота 2 вверх/вниз и обновление кэша раз в 20 тиков.
- `balanced`: радиус 6 блоков, высота 3 вверх/вниз и обновление раз в 10 тиков.
- `high`: радиус 8 блоков, высота 4 вверх/вниз и обновление раз в 5 тиков.
- Ручная настройка радиуса или высоты переводит профиль в `custom`.
- Категории жидкостей, порталов, огня, растений и специальных моделей сохраняются отдельно в `config/blockshape-visualizer.properties`. При выключении категории BlockShape перестаёт применять к ней статический кадр или локально восстанавливать скрытую модель. Для полного скрытия жидкости также выключи её в BlockHider: `/bhider category liquids off`.
- Кэш очищается при смене мира, загрузке и выгрузке чанков; в статусе `/bshape` показываются размер кэша и число уникальных ошибок восстановления текстур.

## Команды
- `/bshape` — показать настройки и команды.
- `/bshape on` — включить.
- `/bshape off` — выключить.
- `/bshape toggle` — переключить.
- `/bshape refresh` — принудительно перестроить кэш блоков и текстур.
- `/bshape quality low|balanced|high` — выбрать мобильный профиль производительности.
- `/bshape category <liquids|portals|fire|plants|special> on|off` — независимо включить или выключить обработку категории текстур.
- `/bshape block minecraft:stone off` — отключить восстановление текстуры указанного блока.
- `/bshape block minecraft:stone on` — снова включить восстановление текстуры этого блока.
- После изменения категорий жидкостей, порталов или огня перезагрузи ресурсы клавишами `F3+T`, чтобы обновить состояния анимации атласа.
- `/bshape reset` — сбросить настройки, включая список исключённых блоков.
- `/bshape radius 8` — горизонтальный радиус 8 блоков (допустимо 2–16).
- `/bshape down 5` — показывать до 5 блоков вниз от уровня игрока (допустимо 0–16).
- `/bshape up 4` — показывать до 4 блоков вверх от уровня игрока (допустимо 0–16).
- `/bshape width 2` — толщина линий (допустимо 1–6).
- `/bshape color rainbow` — отдельный стабильный цвет для каждого типа блока.
- `/bshape color 33CCFF` — единый цвет для всех блоков.

## Сборка
Требуется JDK 25 и Gradle 9.6.0. Для Minecraft 26.3 Fabric рекомендует Loom 1.17+; проект использует Loom 1.19-SNAPSHOT.

```bash
gradle build
```

Готовый JAR после успешной сборки будет в `build/libs/`.

## Зависимости
- Minecraft Java 26.3
- Fabric Loader 0.20.1+
