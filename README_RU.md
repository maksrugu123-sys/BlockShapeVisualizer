# Block Shape Visualizer — Minecraft 26.3 / Fabric

Клиентский мод, показывающий реальные Collision Shape блоков вокруг игрока.
Серверная установка не требуется.

## Функции
- Отображает физическую форму столкновения, а не полный куб блока.
- У каждого типа блока свой стабильный цвет.
- Максимальный радиус контуров увеличен до **32 блоков** (по умолчанию 6).
- Радиус восстановления скрытых текстур настраивается отдельно: 1–32 блока, по умолчанию 8. За пределами этого радиуса остаются контуры без дополнительного восстановления текстур — это LOD для снижения нагрузки.
- Независимая высота поиска: вниз и вверх от игрока по 0–16 блоков (оба значения по умолчанию 3).
- Настраиваемая толщина контура 1–6.
- Можно выбрать один общий цвет или автоматические цвета по типам блоков.
- Построение кэша разбито на порции между клиентскими тиками с жёстким ориентиром около 2,5 мс на проход. Это уменьшает длинные единичные зависания при большом радиусе или загрузке чанков.
- Отдельный бюджет ограничивает число дорогих пересозданий текстурных Mesh за один тик; бюджет автоматически снижается при долгих участках работы и постепенно восстанавливается, когда появляется запас времени.
- Пустые секции чанков пропускаются до чтения отдельных BlockState.
- Объекты за пределами текущего frustum камеры не отправляются в рендер.
- Изменения блоков, чанков и освещения объединяются в одну отложенную перестройку затронутых областей; несколько событий не запускают полную обработку каждое по отдельности.
- Контуры блоков собираются в одну пакетную отправку геометрии на кадр вместо отдельной отправки каждого блока.
- Страховое полное сканирование выполняется редко: раз в 60 секунд для Performance, 30 секунд для Low/Balanced и 10 секунд для High. Движение и игровые события обновляют кэш раньше.
- Два буфера и повторно используемые карты снижают временные выделения памяти между перестройками.
- `performance`: радиус 3 блока, высота 1 вверх/вниз, страховочная проверка раз в 60 секунд и минимальный бюджет работы за тик.
- `low`: радиус 4 блока, высота 2 вверх/вниз и страховочная проверка раз в 30 секунд.
- `balanced`: радиус 6 блоков, высота 3 вверх/вниз и страховочная проверка раз в 30 секунд.
- `high`: радиус 8 блоков, высота 4 вверх/вниз и страховочная проверка раз в 10 секунд.
- Исключения по отдельным ID блоков и namespace сохраняются в конфигурации; это позволяет изолировать конфликтующий мод без отключения всех текстур.
- При совместной установке BlockShape обращается к публичному фильтру BlockHider без compile-time зависимости: если штатный block-entity renderer разрешён, второй baked-слой не добавляется; если BlockHider его скрывает, `/bshape category special on` разрешает локальный fallback в радиусе BlockShape.
- Категории жидкостей, порталов, огня, растений и специальных моделей сохраняются отдельно в `config/blockshape-visualizer.properties`. При выключении категории BlockShape перестаёт применять к ней статический кадр или локально восстанавливать скрытую модель. Для полного скрытия жидкости также выключи её в BlockHider: `/bhider category liquids off`.
- Неизменившиеся меши переиспользуются при обновлении области; перестраиваются только блоки, у которых изменились состояние, соседи, освещение, биом или Ambient Occlusion.
- Кэш очищается при смене мира, загрузке и выгрузке чанков, а также после перезагрузки ресурс-паков/F3+T.
- Статус `/bshape` показывает размер кэша, число использованных и пересозданных текстур, число проверенных позиций, суммарное CPU-время последней перестройки и текущий адаптивный бюджет.

## Команды
- `/bshape` — показать настройки, статистику кэша и команды.
- `/bshape on` — включить.
- `/bshape off` — выключить.
- `/bshape toggle` — переключить.
- `/bshape inspect` — показать ID, категорию, модель, состояние рендеринга и кэша блока, на который направлен прицел.
- `/bshape profile` — показать время подготовки рендера, работу кэша, отсечение секций, число мешей и пакетную отрисовку контуров.
- `/bshape refresh` — принудительно перестроить кэш блоков и текстур.
- `/bshape reload` — штатно перезагрузить ресурс-паки Minecraft, чтобы применить переключение статичных текстур воды, лавы, огня и порталов без клавиш F3+T.
- `/bshape quality performance|low|balanced|high` — выбрать профиль производительности.
- `/bshape category <liquids|portals|fire|plants|special> on|off` — независимо включить или выключить обработку категории текстур.
- `/bshape block minecraft:stone off` — отключить восстановление текстуры указанного блока.
- `/bshape block minecraft:stone on` — снова включить восстановление текстуры этого блока.
- `/bshape namespace examplemod off` — отключить восстановление всех блоков namespace мода.
- `/bshape namespace examplemod on` — снова включить их.
- `/bshape radius 32` — увеличить радиус контуров (допустимо 2–32).
- `/bshape texture-radius 16` — задать радиус восстановления текстур независимо от радиуса контуров (допустимо 1–32).
- `/bshape texture-radius auto` — ограничить радиус текстур максимумом 8 блоков или текущим радиусом, если он меньше.
- `/bshape down 5` — показывать до 5 блоков вниз от уровня игрока (допустимо 0–16).
- `/bshape up 4` — показывать до 4 блоков вверх от уровня игрока (допустимо 0–16).
- `/bshape width 2` — толщина линий (допустимо 1–6).
- `/bshape color rainbow` — отдельный стабильный цвет для каждого типа блока.
- `/bshape color 33CCFF` — единый цвет для всех блоков.
- После изменения категорий воды, лавы, огня и порталов выполни `/bshape reload` (или `F3+T`), чтобы обновить состояния анимации атласа.
- `/bshape reset` — сбросить настройки, включая список исключённых блоков.

## Сборка
Требуется JDK 25 и Gradle 9.8.0 (та же версия используется в GitHub Actions). Для Minecraft 26.3 Fabric рекомендует Loom 1.17+; проект использует Loom 1.19-SNAPSHOT.

```bash
gradle build
```

Готовый JAR после успешной сборки будет в `build/libs/`.

## Зависимости
- Minecraft Java 26.3
- Fabric Loader 0.20.1+
- Fabric API 0.165.2+26.3
- Java 25+

Это исходный проект. JAR не считается проверенным, пока сборка и запуск на Minecraft 26.3 не пройдут успешно.

Для нестандартных моделей, которые не создают меш обычным путём, мод дополнительно пробует штатное отображение модели Minecraft как резервный вариант.
